# Jessica Viviana Rangel Espinosa — Arquitecta

Portafolio web elegante y minimalista para la arquitecta Jessica Viviana Rangel Espinosa, con 8 años de experiencia en diseño arquitectónico, interior y trámites urbanísticos.

## 🎨 Características

- **Diseño minimalista blanco y negro** — Solo color en las imágenes de proyectos
- **Portafolio completo** — 17+ proyectos con galería responsive
- **Línea de tiempo interactiva** — Experiencia profesional organizada cronológicamente
- **Popup de venta** — Sección destacada de apartamentos (Villamira)
- **Formulario de contacto** — Integración directa con WhatsApp
- **Animación del logo** — Intro video en cada carga
- **Responsive design** — Optimizado para desktop, tablet y móvil
- **Smooth scroll** — Experiencia fluida con Lenis
- **Scroll-driven animations** — Animaciones sincronizadas con GSAP + ScrollTrigger

## 🚀 Tech Stack

- **HTML5 + CSS3** — Estilos modernos, Grid y Flexbox
- **JavaScript vanilla** — Sin frameworks, máxima compatibilidad
- **GSAP + ScrollTrigger** — Animaciones avanzadas
- **Lenis** — Smooth scroll library
- **Three.js** — Efectos 3D en secciones especiales
- **CDN resources** — Google Fonts, Lucide icons

## 🎯 Funcionalidades principales

### Galería de proyectos
- Vista destacada con 6 proyectos en desktop, 4 en móvil
- Botón "Ver más" para expandir
- Filtros por categoría
- Cards con grayscale al cargar, color al hover

### Detalle de proyecto
- Scroll full-screen de imágenes
- Timeline interactivo para experiencia profesional
- Modal con PDFs embebidos
- Navegación anterior/siguiente

### Contacto
- Formulario validado con campos semánticos
- Envío directo a WhatsApp
- FAB flotante de WhatsApp
- Tooltip contextual en sección Servicios

### Experiencia del usuario
- Intro video solo se muestra una vez por sesión
- Al retroceder desde un proyecto, muestra la intro sin refrescar
- Popup de venta aparece una sola vez (se reinicia al refrescar)
- Smooth scroll y reveal animados

## 📦 Deploy en Vercel

1. Clona este repositorio
2. Conecta tu cuenta de Vercel a GitHub
3. Crea un nuevo proyecto apuntando a este repositorio
4. Vercel auto-detectará la configuración de `vercel.json`
5. Tu sitio estará vivo en `https://tu-proyecto.vercel.app`
